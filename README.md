# t3rrynguy3n.netlify.app

My personal site. I'm Terry "T3" Nguyen, a barber in Mississauga who builds software.

**Live:** [t3rrynguy3n.netlify.app](https://t3rrynguy3n.netlify.app)

The design is a skin fade: the page steps down the clipper guards from #8 to #0, each section one guard shorter and one shade lighter, ending at the contact form. A guard dial ticks down as you scroll.

## Tech

- One static page plus a blog post. Plain HTML, CSS and a few lines of JavaScript, no build step.
- Fonts: Big Shoulders Display and Hanken Grotesk.
- Hosted on Netlify, which auto-deploys from `main`. The contact form uses Netlify Forms.
- Lighthouse mobile: 98 performance, 100 accessibility, 100 SEO.
