Learnings

I build with AI, which makes it easy to ship things without understanding them. So every time something breaks or surprises me, I write down what happened and what I learned. Newest first.

Oct 23, 2026 · This site

LinkedIn might not show a .webp preview image

My site's link preview used a .webp screenshot. WebP is great on web pages, but some social sites, LinkedIn included, don't reliably show it as a preview card.

Make the share image a 1200×630 PNG or JPG. It's the one image on a site that gets read by other companies' software, not just browsers.

Oct 23, 2026 · This site

Images with a width and height need height: auto

A screenshot on my homepage had been slightly squished since launch. The image tag had width and height set, which is good, because it stops the page jumping while images load. But my CSS shrank the width and left the height fixed.

Whenever CSS resizes an image, add height: auto so it keeps its shape.

Oct 21, 2026 · integrity-check

A hash alone doesn't prove nobody touched a file

My log tamper checker saves a SHA-256 fingerprint of each file, then compares later. The catch: anyone who can edit the logs can probably edit the saved fingerprints too, and then everything still "matches."

Sign the fingerprints with HMAC and a secret key kept somewhere else. Without the key, a forged fingerprint list gets caught. It's still not perfect: someone could swap in an older signed list, and the README says so.

Oct 21, 2026 · llm-api

Free AI APIs come with hidden limits

Three surprises from building on free model tiers. Model names disappear without warning, so code that worked yesterday gets a 404. Groq's free tier allows 8,000 tokens a minute, so long conversations hit the limit fast. And a slow free model can hang a whole script.

When a model 404s, ask the API which models it has now. Keep prompts lean. And always set a timeout on every call.

Oct 2026 · CodeLingo

A strict security policy can force a better design

I wanted a strict Content Security Policy on CodeLingo, with no unsafe-eval. That blocks a whole class of attacks, but my JavaScript challenges needed to run learners' code.

Moving that code into its own locked-down Web Worker let the page drop unsafe-eval, and kept learners' code away from the page and their account. The rule I didn't want to follow made the app safer.

Oct 2026 · Theatre app

Checking a seat is free isn't enough to stop double-booking

If two people book the same seat at the same moment, both requests can check "is it free?", both get yes, and both save.

Put the rule in the database: a unique index allowing one active booking per seat per showtime. The database refuses the second booking no matter how close together they arrive. More in the case study.

Oct 2026 · Windows

PowerShell can quietly break your files' characters

Saving a code file with PowerShell's Set-Content corrupted its special characters. On Windows PowerShell 5.1 it doesn't write UTF-8 unless you tell it to.

Don't use PowerShell to rewrite code files. If you have to, pass -Encoding utf8, and check the diff before committing.

Oct 2026 · T3Trims

Free plans can switch off while you're not looking

My shop's AI receptionist first ran on Supabase's free plan. Free projects get paused when they're quiet, and one day mine was, so the receptionist went offline.

For anything clients rely on, read what the free plan does when nobody's using it. I moved the receptionist into a Netlify function next to the site. More in the case study.
